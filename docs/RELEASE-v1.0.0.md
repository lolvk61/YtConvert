# YtConvert v1.0.0

Первый релиз YtConvert для Windows x64.

- Скачивание видео YouTube с выбором качества до 4K.
- Конвертация в MP4, MKV, WebM, MOV и AVI.
- Извлечение звука в MP3, WAV, M4A, FLAC, OGG, Opus и AAC.
- Создание GIF и обрезка видео и аудио.
- Встроенный плеер, выбор границ по текущей позиции и воспроизведение фрагмента.
- Тёмный интерфейс, анимированные кнопки и новая иконка.

Скачайте **YtConvert-v1.0.0-win-x64.zip**, распакуйте архив целиком и запустите
**YtConvert.exe**. Требуется Windows 10/11 x64.

Python включён в сборку. При первой обработке FFmpeg и Deno скачиваются
автоматически, поэтому для первоначальной подготовки нужен интернет.
Внешние компоненты можно подготовить заранее через `install-tools.cmd`.
Качество скачивания зависит от исходного ролика, дополнительные форматы
создаются перекодированием.

`SHA256SUMS.txt` содержит контрольную сумму ZIP. Исходный код и иконка
распространяются под MIT; лицензии зависимостей находятся внутри архива.
